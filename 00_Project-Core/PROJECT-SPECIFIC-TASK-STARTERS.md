# Project-Specific Task Starters (OrchLayer)

## Review the current pack
Objective: assess whether the current OrchLayer documentation and bridge files still fit the target deployment environment.
Return: strengths, weaknesses, risks, highest-value corrections, and any needed handoff.

## Convert fresh repo state into next orchestration tasks
Objective: inspect current project files and produce the next 3-7 implementation tasks the in-app orchestrator should generate.
Return: structured field packet plus recommended next tasks.

## Check continuity artifacts
Objective: verify whether Session Packets and Handoff Packages remain consistent with the current repository and implementation state.
Return: mismatch report, drift notes, and recommended repair tasks.

## Evaluate extension strategy
Objective: inspect whether the repository and deployment target should stay no-extension, use governed API actions, or use workspace-native integrations.
Return: extension decision note with risks, assumptions, and recommendation.
