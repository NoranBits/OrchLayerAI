# 01_Project-State

## Purpose

This directory contains mutable repository-specific state. This includes repo profiles, active capability manifests, and temporary implementation plans.

## Role

Classified as: **project state**

- **REPO-PROFILE.yaml**: Repo-specific metadata (stack, paths, rules).
- **CAPABILITY-MANIFEST.current.json**: Verified runtime capability of the active AI agent.
- **Implementation-Plan.md**: Active technical work plans.

## Storage Rule

Mutable artifacts live here. Stable core principles belong in `00_Project-Core/`.
